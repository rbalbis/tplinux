# Module 4 — Permissions, partie 1
## 4.3 — L'octal et chmod

**Commandes utilisées :**

`chmod` — change les permissions. *Pourquoi ce nom : "CHange MODe" — le mot "mode" est le terme technique Unix pour désigner les permissions d'un fichier (issu du champ `st_mode` de l'appel système `stat()`, vu au 1.4).*
- `chmod u+x f` → forme symbolique (ajoute x au propriétaire).
- `chmod 640 f` → forme octale, remplace tout d'un coup.
- `-R` → récursif (prudence : mélange fichiers/dossiers).

## Calcul octal

`r=4, w=2, x=1`, on additionne par catégorie. `755 = rwxr-xr-x`, `644 = rw-r--r--`, `600 = rw-------`.

## Exercice

```bash
chmod 640 data/secret.txt
stat -c '%a %A %n' data/secret.txt
```

**À retenir** : fichiers `644` (données) / `755` (scripts) / `600` (secrets). `chmod -R 777` n'est jamais une solution, c'est un incident de sécurité qui commence.
