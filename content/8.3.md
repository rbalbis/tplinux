# Module 8 — Shell utilisable au quotidien
## 8.3 — Codes retour : $?, &&, ||

**Notions utilisées :**

`$?` — contient le CODE RETOUR de la dernière commande exécutée. `0` = succès, tout autre nombre = échec (le code précis dépend de la commande).

`cmd1 && cmd2` — exécute `cmd2` SEULEMENT SI `cmd1` a réussi (code retour 0).

`cmd1 || cmd2` — exécute `cmd2` SEULEMENT SI `cmd1` a échoué.

## Exercice

```bash
ls /existe-pas ; echo $?
ls /etc ; echo $?
ls /etc && echo OK || echo KO
```

**Pourquoi c'est central** : tout script sérieux teste les codes retour avant de continuer — un script qui enchaîne des commandes sans vérifier `$?` peut continuer à s'exécuter après un échec silencieux, avec des conséquences en cascade.

**À retenir** : `0` = succès (convention héritée du C, où une fonction qui "ne signale aucune erreur" retourne 0) — c'est l'inverse de l'intuition binaire habituelle (où 0 = faux, 1 = vrai).
