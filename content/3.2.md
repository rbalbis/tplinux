# Module 3 — Flux et texte
## 3.2 — grep, filtrer par motif

**Commandes utilisées :**

`grep` — affiche les lignes contenant un motif. *Pourquoi ce nom : c'est l'anecdote la plus célèbre d'Unix — le nom vient d'une commande de l'éditeur `ed` des années 70, "g/re/p" (Global search for a Regular Expression, then Print) ; les utilisateurs tapaient si souvent cette séquence qu'elle a été extraite en commande séparée, gardant l'acronyme collé tel quel.*
- `-i` → insensible à la casse.
- `-n` → affiche le numéro de ligne.
- `-v` → inverse (lignes NE contenant PAS le motif).
- `-r` → cherche récursivement dans un dossier.
- `-c` → compte les lignes matchées.
- `-E` → active les regex étendues (`|` = "ou").
- `-o` → n'affiche que la partie qui matche, pas la ligne entière.

## Exercice

```bash
grep -c "ERROR" logs/app.log
grep -Ec "ERROR|WARN" logs/app.log
grep -v "DEBUG" logs/app.log
```

**À retenir** : `grep` cherche dans le CONTENU, `find` cherche des fichiers par métadonnées.
