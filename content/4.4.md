# Module 4 — Permissions, partie 1
## 4.4 — umask

**Commandes utilisées :**

`umask` — définit les permissions par défaut des NOUVEAUX fichiers/dossiers. *Pourquoi ce nom : "user mask" — un MASQUE qui retire des bits, littéralement.*

## Le mécanisme (pas une soustraction, un masquage)

Fichier max = `666` (jamais de x par défaut, même pas pour un dossier), dossier max = `777`. Calcul pratique : `permissions finales = max - umask`.

`umask 022` → fichier `644`, dossier `755` (le défaut serveur classique).
`umask 077` → fichier `600`, dossier `700` (poste sensible, isolation totale).

## Exercice

```bash
umask
touch t1; mkdir d1
stat -c '%a %n' t1 d1
```

**Piège à connaître** : `umask` ne peut JAMAIS donner `x` à un fichier fraîchement créé, quel que soit son réglage — parce que la demande de base d'un fichier ne contient jamais `x` (contrairement à un dossier). Il faut toujours un `chmod +x` explicite après coup pour un script.

**À retenir** : `umask` n'est pas persistant (repart à zéro à chaque session) — pour le fixer durablement, l'ajouter dans `~/.bashrc`.
