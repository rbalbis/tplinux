# Module 7 — Réseau
## 7.1 — La méthode en couches, interface et routage

## La méthode : diagnostiquer TOUJOURS dans cet ordre

1. Interface & IP (`ip a`) → 2. Routage (`ip r`) → 3. Joignabilité (`ping`/`traceroute`) → 4. DNS (`dig`) → 5. Port (`nc`/`ss`) → 6. Application (`curl`).

Inutile de tester la couche 6 si la couche 1 échoue déjà.

**Commandes utilisées :**

`ip` — configuration réseau moderne, remplace `ifconfig`/`route`/`arp`. *Pourquoi ce nom : contraction directe d'"Internet Protocol".*
- `ip a` (ou `ip addr`) → liste les interfaces et leurs adresses.
- `ip r` (ou `ip route`) → affiche la table de routage.
- `-br` → format bref, plus lisible.

## Exercice

```bash
ip -br a
ip r
cat /etc/resolv.conf
```

**À retenir** : une IP en `172.x.x.x` ou `10.x.x.x` = adresse privée (NAT), typique d'un conteneur/VM/WSL2 — ce n'est pas l'IP "réelle" de la machine sur le réseau de l'entreprise.
