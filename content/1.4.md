# Module 1 — Se repérer
## 1.4 — file, stat et les 3 dates

**Commandes utilisées :**

`file` — dit ce qu'est réellement un fichier, en lisant son contenu. *Pourquoi ce nom : elle fait exactement ce qu'annonce son nom.*

`stat` — métadonnées complètes d'un fichier. *Pourquoi ce nom : vient de l'appel système `stat()` du langage C, utilisé depuis 50 ans pour récupérer le "status" d'un fichier — la commande est un habillage en ligne de commande de cette fonction.*
- `-c '%a %A %n'` → format personnalisé (octal, symbolique, nom).

## Exercice

```bash
file projet/build/artefact.bin
stat logs/app.log
```

Sous Linux, l'extension d'un fichier n'a AUCUNE valeur technique — seul le contenu compte.

Les trois dates : **mtime** (contenu modifié), **ctime** (métadonnées modifiées — un `chmod` la change), **atime** (dernier accès).

**À retenir** : ne jamais faire confiance à une extension sous Linux, toujours vérifier avec `file`.
