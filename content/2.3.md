# Module 2 — Manipuler des fichiers
## 2.3 — find, l'outil pivot en mission

**Commandes utilisées :**

`find` — cherche des fichiers selon leurs métadonnées (nom, taille, date, type), jamais leur contenu. *Pourquoi ce nom : sans détour, "find" = "trouver".*
- `-name "*.log"` → filtre par nom.
- `-type f` / `-type d` → fichier ou dossier.
- `-size +100k` → plus de 100 Ko.
- `-mtime -7` → modifié il y a MOINS de 7 jours (le signe `-` = "inférieur à", `+` = "supérieur à" — piège classique).
- `-delete` → supprime directement les résultats.
- `-exec cmd {} \;` → exécute une commande sur chaque résultat trouvé.

## Exercice

```bash
find . -name "*.log" -type f
find . -size +100k -mtime -7
find . -name "vieux-*" -type f -exec mv {} archive/2019-2020/ \;
```

**Différence avec `grep`** : `find` répond à "où est-ce ?" (métadonnées), `grep` répond à "qu'est-ce qu'il y a dedans ?" (contenu). On les combine souvent : `find . -name "*.log" -exec grep -l ERROR {} \;`.

**À retenir** : toujours tester `find` SANS `-delete`/`-exec` d'abord, pour vérifier ce qui serait touché.
