# Module 2 — Manipuler des fichiers
## 2.1 — Créer, copier, déplacer, supprimer

**Commandes utilisées :**

`mkdir` — crée un dossier. *Pourquoi ce nom : "make directory".*
- `-p` → crée aussi les parents manquants, sans erreur si le dossier existe déjà.

`touch` — crée un fichier vide, ou met à jour sa date de modification s'il existe déjà. *Pourquoi ce nom : anecdote amusante — le nom vient de l'idée de "toucher" un fichier sans le modifier, comme on toucherait un objet du doigt pour signaler qu'on est passé par là, sans rien y changer à l'intérieur.*

`cp` — copie un fichier. *Pourquoi ce nom : "copy".*
- `-r` → récursif, obligatoire pour un dossier.
- `-p` → préserve permissions et dates.
- `-a` → "archive", combine récursif + préservation complète (permissions, dates, liens symboliques).

`mv` — renomme ou déplace. *Pourquoi ce nom : "move" — sous Linux, renommer et déplacer sont techniquement la même opération (changer l'entrée dans le dossier parent).*

`rm` — supprime, définitivement, sans corbeille. *Pourquoi ce nom : "remove".*
- `-r` → récursif (dossier).
- `-i` → demande confirmation avant chaque suppression.

## Exercice

```bash
mkdir -p ~/tp-linux/livrables/2026/{q1,q2,q3,q4}
cp -p logs/app.log logs/app.log.bak
```

**Anecdote** : `rm` n'a jamais eu de corbeille par conception — Unix a été pensé pour des administrateurs système, pas pour le grand public ; l'idée d'un filet de sécurité est arrivée bien plus tard avec les interfaces graphiques.

**À retenir** : toujours vérifier avec `ls` la même expression avant de la passer à `rm`.
