# Module 3 — Flux et texte
## 3.4 — sed et tr : transformer du texte

**Commandes utilisées :**

`sed` — transforme du texte ligne par ligne. *Pourquoi ce nom : "Stream EDitor" — un éditeur de texte conçu pour traiter un FLUX de données automatiquement, sans interface interactive, contrairement à `vi`.*
- `s/ancien/nouveau/g` → substitution, `g` = toutes les occurrences de la ligne.
- `-n '10,20p'` → affiche seulement les lignes 10 à 20.
- `-i.bak` → modifie sur place, garde une sauvegarde `.bak`.

`tr` — traduit caractère par caractère. *Pourquoi ce nom : "translate".*
- `tr 'a-z' 'A-Z'` → minuscules vers majuscules.
- `-d` → supprime les caractères indiqués.

## Exercice

```bash
sed 's/Geneve/Genève/g' data/salaires.csv > data/salaires-corrige.csv
sed -i.bak 's/Geneve/Genève/g' data/salaires.csv
```

**À retenir** : sans `-i`, `sed` n'affiche que le résultat, ne modifie jamais le fichier original.
