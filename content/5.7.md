# Module 5 — Identités et bits spéciaux
## 5.7 — chattr : l'immuabilité

**Commande utilisée :**

`chattr` — modifie les attributs étendus d'un fichier (au-delà des permissions classiques). *Pourquoi ce nom : "CHange ATTRibute".*
- `+i` → rend le fichier IMMUABLE : même ROOT ne peut plus le modifier, le renommer ou le supprimer.
- `-i` → retire l'immuabilité.

`lsattr` — affiche les attributs étendus. *Pourquoi ce nom : "LiSt ATTRibutes".*

## Exercice

```bash
sudo chattr +i fichier.conf
sudo rm fichier.conf   # échoue, même en root : "Operation not permitted"
sudo chattr -i fichier.conf
sudo rm fichier.conf   # fonctionne cette fois
```

**Cas d'usage réel** : figer un fichier de configuration qu'un script ou un déploiement automatique aurait tendance à réécrire à tort.

**À retenir** : c'est un niveau de protection AU-DESSUS des permissions classiques — un attribut du système de fichiers, pas une permission u/g/o.
