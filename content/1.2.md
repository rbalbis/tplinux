# Module 1 — Se repérer
## 1.2 — Navigation : chemins absolus et relatifs

**Commandes utilisées :**

`pwd` — affiche le dossier courant. *Pourquoi ce nom : acronyme de "Print Working Directory".*

`cd` — change de dossier. *Pourquoi ce nom : acronyme de "Change Directory".*
- `cd /etc` → chemin absolu (commence par `/`), t'emmène exactement là peu importe d'où tu partais.
- `cd ..` → monte d'un niveau (le parent).
- `cd ~` → retourne à ton home.
- `cd -` → retourne au dossier précédent. *Anecdote : ce tiret est une convention Unix générale pour "la valeur précédente" — on la retrouve ailleurs, par exemple pour désigner l'entrée/sortie standard dans certains outils.*

## Exercice

```bash
cd /var/log
pwd
cd -
pwd
```

Chemin absolu = sans ambiguïté, à privilégier dans les scripts. Chemin relatif = part du dossier courant (`../autre-dossier` remonte puis redescend).

**À retenir** : `.` = ici, `..` = parent, `~` = home, `-` = précédent.
