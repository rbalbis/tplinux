# Module 7 — Réseau
## 7.6 — Ports : ss et nc

**Commandes utilisées :**

`ss` — liste les connexions et ports en écoute. *Pourquoi ce nom : "Socket Statistics" — remplace l'ancien `netstat`, plus rapide.*
- `-tulpn` → TCP (t), UDP (u), écoute seulement (l), processus (p), numérique (n).

`nc` (netcat) — teste une connexion à un port. *Pourquoi ce nom : le "netcat" est décrit par ses propres créateurs comme le "couteau suisse" du réseau — un outil brut et polyvalent pour manipuler des connexions TCP/UDP.*
- `-zv host port` → teste sans envoyer de données (`-z`), verbeux (`-v`).

## Exercice

```bash
ss -tulpn
nc -zv www.admin.ch 443
```

**Distinction capitale** : `127.0.0.1:PORT` = accessible SEULEMENT depuis la machine elle-même. `0.0.0.0:PORT` = accessible depuis le réseau entier — le point n°1 à vérifier en revue de sécurité (une base de données exposée par erreur sur `0.0.0.0`).

**À retenir** : un port fermé répond vite ("refused"), un port FILTRÉ par un pare-feu ne répond jamais (timeout) — le silence est la signature d'un filtrage actif.
