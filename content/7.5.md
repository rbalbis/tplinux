# Module 7 — Réseau
## 7.5 — /etc/hosts et l'ordre de résolution (nsswitch)

**Fichiers utilisés :**

`/etc/hosts` — table de correspondance nom→IP LOCALE, consultée avant tout serveur DNS.

`/etc/nsswitch.conf` — définit l'ORDRE des sources de résolution. *Pourquoi ce nom : "Name Service SWITCH" — l'aiguillage entre les différentes sources de résolution de noms.*
- `hosts: files dns` → regarde d'abord `/etc/hosts` ("files"), puis le DNS seulement si rien trouvé.

## Exercice

```bash
sudo sh -c 'echo "127.0.0.1 test-client.local" >> /etc/hosts'
ping test-client.local   # fonctionne, lit /etc/hosts
dig test-client.local    # échoue, dig ignore /etc/hosts et interroge directement le DNS
```

**Pourquoi la différence** : `ping` utilise les fonctions de résolution standard du système, qui respectent `/etc/nsswitch.conf`. `dig` est un outil spécialisé qui interroge TOUJOURS directement un serveur DNS, en ignorant délibérément `/etc/hosts`.

**À retenir** : `/etc/hosts` est prioritaire sur le DNS par défaut — pratique pour tester un nom sans toucher au DNS réel.
