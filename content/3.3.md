# Module 3 — Flux et texte
## 3.3 — cut, sort, uniq : extraire et compter

**Commandes utilisées :**

`cut` — extrait des colonnes. *Pourquoi ce nom : elle "découpe" chaque ligne pour n'en garder qu'un morceau.*
- `-d';'` → délimiteur de colonnes.
- `-f1,3` → champs 1 et 3.

`sort` — trie les lignes.
- `-t';' -k4 -n` → trie sur la 4e colonne (délimiteur `;`), numériquement.
- `-r` → ordre décroissant.
- `-h` → comprend les unités Ko/Mo/Go (utile après `du -h`).

`uniq` — regroupe et compte les doublons ADJACENTS uniquement. *Pourquoi ce nom : "unique".*
- `-c` → affiche le nombre d'occurrences de chaque ligne.

## Exercice — la chaîne d'or de l'analyse de logs

```bash
grep "ERROR" logs/app.log | cut -d' ' -f4- | sort | uniq -c | sort -nr | head -3
```

**À retenir** : `uniq` ne détecte QUE les doublons consécutifs — il faut presque toujours `sort` avant.
