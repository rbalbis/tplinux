# Module 8 — Shell utilisable au quotidien
## 8.1 — Variables d'environnement et PATH

**Commandes utilisées :**

`echo $PATH` — affiche la liste des dossiers où le shell cherche les exécutables, séparés par `:`.

`export VAR=valeur` — définit une variable d'environnement, visible par les programmes lancés depuis ce shell. *Pourquoi ce nom : la variable est "exportée" vers les processus enfants — sans `export`, une variable reste locale au shell courant.*

`which` — indique le chemin complet d'une commande trouvée dans le PATH.

`type cd` — comme `which`, mais reconnaît aussi les commandes internes du shell (builtins) que `which` ne voit pas toujours.

## Exercice

```bash
echo $PATH
which ls
export PATH="$PATH:~/tp-linux/scripts"
```

**Pourquoi `./script.sh` et pas juste `script.sh`** : le dossier courant n'est délibérément PAS dans le PATH par défaut, pour des raisons de sécurité — sinon un fichier malveillant nommé comme une commande courante (`ls`, `cd`) posé dans un dossier piégé pourrait s'exécuter à ta place.

**À retenir** : `~/.bashrc` est l'endroit pour rendre un ajout au PATH permanent (sinon perdu à la fermeture du terminal).
