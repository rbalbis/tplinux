# Module 5 — Identités et bits spéciaux
## 5.4 — SGID

**Commande utilisée :**

`chmod g+s rep` ou `chmod 2775 rep` — pose le bit SGID. *Pourquoi ce nom : "Set Group ID (upon execution)".*

## Sur un dossier (le cas le plus utile)

Tout fichier créé DANS ce dossier hérite automatiquement du GROUPE DU DOSSIER, pas du groupe primaire de son créateur.

## Exercice — le scénario du dossier de projet partagé

```bash
sudo chmod 2770 /srv/partage
sudo -u bob touch /srv/partage/doc-bob.txt
ls -l /srv/partage/doc-bob.txt
```

Le fichier de bob doit appartenir au groupe `projet-x`, pas à `bob`.

**Le problème qui reste** : le fichier hérite du bon groupe, mais ses droits dépendent encore de l'umask du créateur (souvent `644`, groupe en lecture seule). Solution : `umask 002` dans le `.bashrc` des utilisateurs, OU une ACL par défaut (5.6, la solution propre).

**À retenir** : SGID sur dossier = solution standard du travail collaboratif, résout le problème "chaque fichier créé a le mauvais groupe".
