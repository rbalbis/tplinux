# Module 1 — Se repérer
## 1.6 — Documentation et historique

**Commandes utilisées :**

`man` — manuel complet d'une commande. *Pourquoi ce nom : abréviation de "manual".*

`apropos` — cherche des commandes par mot-clé. *Pourquoi ce nom : mot emprunté tel quel au français "à propos" — la commande cherche les pages "pertinentes" par rapport à un mot donné.*

`history` — liste des commandes tapées.

`!N` — réexécute la commande n°N.

`Ctrl-R` — recherche interactive dans l'historique.

## Exercice

```bash
man ls
apropos network
```

**À retenir** : `man` fonctionne sans Internet. `Ctrl-R` est le réflexe le plus rentable à automatiser dans les doigts.
