# Module 8 — Shell utilisable au quotidien
## 8.2 — Alias

**Commande utilisée :**

`alias` — crée un raccourci pour une commande plus longue. *Pourquoi ce nom : sans détour, un "alias" est un autre nom pour la même chose.*
- `alias ll='ls -alh'` → définit le raccourci.
- `unalias ll` → le retire.

## Exercice

```bash
alias ll='ls -alh'
alias dfh='df -h'
ll
```

Un alias défini directement dans le terminal disparaît à la fermeture de la session — pour le rendre permanent, il faut l'ajouter dans `~/.bashrc` puis `source ~/.bashrc` pour l'activer immédiatement sans rouvrir de terminal.

**Anecdote** : `source` (ou son raccourci `.`) exécute un script DANS le shell courant plutôt que dans un sous-processus séparé — c'est la seule façon pour qu'un alias ou une variable d'environnement défini dans un fichier affecte réellement ton terminal actuel.

**À retenir** : les alias sont purement cosmétiques pour l'utilisateur — jamais utilisés dans un script (qui doit rester portable et explicite).
