# Module 6 — Processus et système
## 6.1 — ps, les colonnes et l'arbre des processus

**Commandes utilisées :**

`ps` — liste les processus. *Pourquoi ce nom : "Process Status".*
- `aux` (format BSD) → colonnes USER, PID, %CPU, %MEM, STAT, COMMAND.
- `-ef` (format System V) → ajoute PPID (le parent).
- `-p 1 -o comm=` → nom du processus PID 1 (systemd, init, ou autre selon l'environnement).

`pstree` — affiche directement l'arbre des processus (qui a lancé qui).
- `-p` → avec les PID entre parenthèses.

`top` — vue interactive triée par CPU, mise à jour en direct. *Pourquoi ce nom : montre le "top" (sommet) des processus les plus gourmands.*

## Exercice

```bash
ps aux | head
ps -p 1 -o comm=
ps aux --sort=-%mem | head -6
```

**À retenir** : `ps -p 1 -o comm=` dit immédiatement si `systemctl` va fonctionner sur cette machine (réponse "systemd") ou pas (conteneur, BusyBox...).
