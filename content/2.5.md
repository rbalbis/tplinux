# Module 2 — Manipuler des fichiers
## 2.5 — Globbing et guillemets

**Commandes utilisées :**

Pas de nouvelle commande ici — le sujet est le comportement du SHELL lui-même avant qu'une commande ne s'exécute.

- `*` → remplace n'importe quelle suite de caractères (y compris zéro).
- `?` → remplace exactement UN caractère.
- `ls -d */` → liste uniquement les dossiers (le `/` final ne matche que les dossiers, `-d` empêche de lister leur contenu).

## Exercice

```bash
echo *
ls data/*.csv
ls projet/src/?ain.c
touch "mon fichier.txt"
```

Le shell développe `*`/`?` en une liste d'arguments AVANT même de lancer la commande — `ls` ne voit jamais l'étoile, il reçoit directement la liste de noms.

Sans guillemets, `touch mon fichier.txt` est compris comme 3 arguments séparés (le shell découpe aux espaces) → 2 fichiers créés au lieu d'un seul avec un espace dans le nom.

**À retenir** : toujours guillemeter un nom de fichier/dossier contenant un espace.
