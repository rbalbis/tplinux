# Module 3 — Flux et texte
## 3.1 — Lire un fichier

**Commandes utilisées :**

`cat` — affiche tout le fichier d'un coup. *Pourquoi ce nom : "concatenate" — à l'origine conçu pour CONCATÉNER plusieurs fichiers ensemble (`cat a.txt b.txt > c.txt`), l'affichage à l'écran n'était qu'un effet de bord de cette fonction.*

`less` — pageur interactif (`/` cherche, `G` fin, `q` quitte). *Pourquoi ce nom : blague d'informaticien — son ancêtre s'appelait `more` ("plus"), et `less` a été créé pour le remplacer en mieux, avec le jeu de mots "less is more" (moins c'est plus).*

`head` / `tail` — début / fin d'un fichier.
- `tail -f` → suit le fichier en temps réel, affiche chaque nouvelle ligne ajoutée.

`wc` — compte. *Pourquoi ce nom : "word count".*
- `-l` → lignes, `-c` → octets.

## Exercice

```bash
wc -l logs/app.log
tail -f logs/app.log
```

**À retenir** : jamais `cat` sur un fichier de plusieurs Go — toujours `less` pour explorer.
