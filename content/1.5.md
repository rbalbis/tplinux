# Module 1 — Se repérer
## 1.5 — L'arborescence FHS

**Commandes utilisées :**

`tree` — vue arborescente d'un dossier. *Pourquoi ce nom : dessine littéralement un "arbre" ASCII (│├└) de la hiérarchie.*
- `-L 2` → limite la profondeur affichée.

## Structure standard

`/etc` (configuration), `/var/log` (journaux), `/home` (dossiers perso), `/usr/bin` (commandes), `/tmp` (temporaire), `/opt` (apps tierces), `/proc` et `/dev` (systèmes de fichiers VIRTUELS générés par le noyau — 0 octet dans `ls -l` même si `cat` affiche du contenu), `/mnt` (montage temporaire).

**Anecdote sur /etc** : le nom vient de "et cetera" — à l'origine, le fourre-tout pour "tout ce qui ne rentre pas ailleurs". Avec le temps ça s'est standardisé en "configuration du système", mais le nom garde la trace de ce passé de tiroir à tout mettre.

## Exercice

```bash
tree -L 2 /
cat /proc/cpuinfo | head -20
```

**À retenir** : config dans `/etc`, logs dans `/var/log`, temporaire dans `/tmp`.
