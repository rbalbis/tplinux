# Module 2 — Manipuler des fichiers
## 2.4 — Espace disque (du/df) et archives (tar)

**Commandes utilisées :**

`du` — taille de fichiers/dossiers. *Pourquoi ce nom : "disk usage".*
- `-s` → résumé global (pas le détail récursif).
- `-h` → lisible (Ko/Mo/Go).

`df` — espace occupé/libre par système de fichiers monté. *Pourquoi ce nom : "disk free".*

`tar` — crée/extrait des archives. *Pourquoi ce nom : "Tape ARchive" — à l'origine, cet outil servait à écrire des sauvegardes sur bande magnétique (tape), une technologie de stockage des années 70 ; le nom a survécu bien après la disparition des bandes.*
- `-c` → créer, `-x` → extraire, `-t` → lister sans extraire, `-z` → compression gzip, `-f` → nom du fichier archive.

## Exercice

```bash
du -sh ~/tp-linux/*
df -h
tar -czf projet-$(date +%F).tar.gz projet/
tar -tzf projet-*.tar.gz
tar -xzf projet-*.tar.gz -C /tmp/restore
```

**À retenir** : `du` regarde des fichiers, `df` regarde des volumes entiers — différence capitale en diagnostic "disque plein".
