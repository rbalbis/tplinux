# Module 7 — Réseau
## 7.3 — DNS : nslookup, dig et types d'enregistrements

**Commandes utilisées :**

`nslookup` — interroge un serveur DNS. *Pourquoi ce nom : "NameServer LOOKUP".*

`dig` — outil DNS plus complet et détaillé. *Pourquoi ce nom : "Domain Information Groper" — littéralement "celui qui fouille les informations de domaine", un acronyme volontairement un peu humoristique des créateurs BIND dans les années 90.*
- `+short` → juste la réponse, sans le détail.
- `MX` / `NS` / `TXT` / `AAAA` → types d'enregistrements (mail, serveurs faisant autorité, texte libre/SPF, IPv6).
- `-x IP` → reverse DNS (IP → nom).

## Exercice

```bash
dig www.admin.ch
dig MX admin.ch +short
dig -x 8.8.8.8 +short
```

**Le TTL** (Time To Live, en secondes dans la réponse `dig`) dit combien de temps une réponse reste en cache — on le réduit avant une migration planifiée pour que le changement se propage vite.

**À retenir** : le reverse DNS (IP→nom) est souvent incohérent avec le forward (nom→IP) car ils sont gérés par des acteurs différents (propriétaire du domaine vs propriétaire de la plage IP).
