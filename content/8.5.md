# Module 8 — Shell utilisable au quotidien
## 8.5 — Écrire un script bash

**Éléments utilisés :**

`#!/bin/bash` — le SHEBANG, première ligne d'un script, indique quel interpréteur utiliser. *Pourquoi ce nom : contraction de "SHArp" (le symbole #) + "BANG" (le symbole ! en argot informatique) — les deux caractères qui composent la ligne.*

`$1`, `$2`... — paramètres passés au script.

`if [ ! -f "$1" ]; then ... fi` — teste si un fichier n'existe PAS (`-f` = "is a file"), et agit en conséquence.

`exit 1` — termine le script avec un code d'erreur (rappel du 8.3 : `0` = succès).

`for f in logs/*.log; do ... done` — boucle sur une liste de fichiers.

## Exercice

```bash
#!/bin/bash
if [ ! -f "$1" ]; then
  echo "Fichier introuvable : $1" >&2
  exit 1
fi
echo "Date: $(date), Host: $(hostname)"
```

**À retenir** : un script a besoin de `r` ET `x` (rappel module 4) — sans `r`, l'interpréteur ne peut même pas lire ce qu'il doit exécuter.
