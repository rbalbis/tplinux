# Module 5 — Identités et bits spéciaux
## 5.6 — ACL

**Commandes utilisées :**

`getfacl` — affiche les ACL d'un fichier. *Pourquoi ce nom : "get file ACL" (ACL = "Access Control List").*

`setfacl` — pose une ACL. *Pourquoi ce nom : "set file ACL".*
- `-m u:carla:r--` → ajoute une règle pour l'utilisatrice carla.
- `-m g:audit:r-x` → ajoute une règle pour un groupe.
- `-d -m g:projet-x:rwx rep` → ACL PAR DÉFAUT sur un dossier — héritée automatiquement par tout ce qui y sera créé (équivalent ACL du SGID, mais avec des permissions précises, pas juste le groupe).
- `-x` → retire une règle. `-b` → purge tout.

## Le problème que les ACL résolvent

Le modèle u/g/o classique ne connaît qu'UN SEUL groupe. Impossible d'exprimer "ce fichier, en plus, lisible par Carla spécifiquement" sans les ACL.

## Exercice

```bash
setfacl -m u:carla:r-- /srv/partage/doc.txt
getfacl /srv/partage/doc.txt
ls -l /srv/partage/doc.txt   # repérer le "+" en fin de ligne
```

**À retenir** : un `+` à la fin de la chaîne de permissions dans `ls -l` signale une ACL — `ls -l` seul est trompeur sur un système avec ACL, il faut `getfacl`.
