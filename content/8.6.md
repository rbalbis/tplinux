# Module 8 — Shell utilisable au quotidien
## 8.6 — cron

**Commande utilisée :**

`crontab` — édite/liste les tâches planifiées d'un utilisateur. *Pourquoi ce nom "cron" : du grec "chronos" (le temps) — le démon `cron` exécute des tâches à intervalles réguliers en arrière-plan depuis les tout débuts d'Unix.*
- `-e` → édite (ouvre `vi` par défaut !). `-l` → liste.

## La syntaxe à 5 champs

```
minute heure jour_du_mois mois jour_de_la_semaine   commande
0      7     *            *    *                     /chemin/audit.sh
```
→ "tous les jours à 7h00".

## Exercice

```bash
crontab -e
# ajouter : 0 7 * * * /home/consultant/tp-linux/scripts/audit.sh >> ~/tp-linux/logs/audit.log 2>&1
```

**Anecdote** : `*` dans chaque champ signifie "à chaque valeur possible" — un système hérité tel quel depuis les années 70, jamais remplacé malgré sa syntaxe peu intuitive au premier abord.

**À retenir** : cron n'a AUCUNE journalisation native (contrairement aux timers systemd du module 9) — toujours rediriger la sortie du script vers un fichier de log (`>> fichier 2>&1`), sinon les erreurs disparaissent silencieusement.
