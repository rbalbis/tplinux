# Module 1 — Se repérer
## 1.1 — Contexte de base : qui, où, quoi

**Commandes utilisées :**

`whoami` — affiche ton nom d'utilisateur. *Pourquoi ce nom : littéralement "who am i" collé en un seul mot — la question que tu poses au système.*

`id` — affiche ton identité complète (UID, GID, groupes). *Pourquoi ce nom : abréviation d'"identity".*

`hostname` — affiche le nom de la machine. *Pourquoi ce nom : en jargon réseau, un "host" désigne toute machine connectée à un réseau — donc littéralement "le nom de cet hôte-ci".*

`uname` — infos système.
- `-a` → tout d'un coup (noyau, version, architecture). *Pourquoi ce nom : "Unix name", conçu à l'origine pour identifier la variante d'Unix utilisée — utile à l'époque où il existait des dizaines d'Unix incompatibles entre eux.*

`uptime` — depuis combien de temps la machine tourne. *Pourquoi ce nom : littéralement "up time" — le temps depuis lequel le système est "up" (debout, actif), par opposition à "down" (en panne/éteint).*

## Exercice

```bash
whoami; hostname; uname -a; date
```

**À retenir** : ces commandes sont tes 10 premières secondes sur une machine inconnue.
