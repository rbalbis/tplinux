# TP Linux — rappels quotidiens

Contenu et état de rotation pour les rappels pédagogiques automatiques du TP Linux (préparé par Mathieu).

- `content/` — 53 mini-cours, un par sous-module (modules 1 à 9)
- `index.json` — index id → module/titre/fichier
- `rotation-state.json` — ordre mélangé + pointeur courant (mis à jour à chaque envoi par les routines planifiées)
